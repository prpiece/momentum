# Everything arriving from outside goes through one server function

Sent tasks from friends, the Discord, Slack and Telegram bots, and the personal webhook all mean the same thing: text from outside lands in one account's Inbox. They share one Supabase Edge Function. It verifies the caller (the friendship, the platform's request signature, or the webhook secret), resolves the linked account, parses the text with `src/domain/quickAdd.ts` (the same parser as the app, so "buy milk tomorrow !high" means the same everywhere), and inserts the task as a normal synced row. Each platform adapter only translates its request and reply formats. We rejected one function per platform (the parsing, account linking and rate limits would be written three to five times) and holding chat connections in the desktop app (Slack Socket Mode and the Discord Gateway would need a shared secret inside every installed copy, and only work while the app is open). This rules out reading arbitrary chat messages ("@Momentum …" in a channel): slash commands and direct messages only.
