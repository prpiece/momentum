# v1.1 launch checklist

What's left before Accounts and sync ships. Built so far: commits `1f1dc99` and `1f3977b` (PLAN D224–D226). Tick items off here as they're done.

## You: Supabase dashboard and accounts

- [ ] **Email sender:** Gmail app password (2-step verification on, then myaccount.google.com → App passwords). In Authentication → Emails → SMTP Settings: host `smtp.gmail.com`, port `587`, your Gmail address as the username and sender, the app password as the password. Switch to Resend with your own domain later (only the SMTP settings change).
- [ ] **Email templates:** set **Magic Link** and **Confirm signup** to the contents of `supabase/templates/code.html`, with the subject "Your Momentum code".
- [ ] **Code length:** in Authentication → Providers → Email, check that the email OTP length is **6**. The app only accepts 6 digits.
- [ ] **Email rate limit:** in Authentication → Rate Limits, raise "emails per hour" above the default.
- [ ] **Push the server schema** (it asks for the database password):
  ```bash
  supabase link --project-ref tfuljwzkeylzwwzppdtv
  supabase db push
  ```
- [x] Support email on the pages.
- [ ] **Read the Terms and Privacy policy** in `site/` and confirm they're true for you. They are a plain-language draft, not legal advice, so have them checked if you can.
- [x] Decided: v1.1 ships with email sign-in only (D227).
